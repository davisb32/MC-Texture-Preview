FROM BLUEPRINT TO BLOCKS

A wall, without the guesswork.

  1. Import a photo or a grayscale PNG. Its width and height become the wall dimensions in blocks; the app never silently resizes it. In Image adjustments, enable quantization to edit levels, grain and dithering.
  2. Open Block library or click a palette slot, then click or drag a thumbnail to assign it. The Upload PNG button below the palette still lets you upload an individual texture. The library reads textures/index.json and the PNGs listed there.
  3. Load another image anytime: exact grayscale matches keep their textures. New shades start white. While quantization is enabled, all selected shades stay in the palette even if some have zero pixels, so their textures survive adjustments. Changing the number of steps keeps exact grayscale matches.
  4. Scroll to zoom and drag to pan. Close up, pixels stay sharp. At a distance, the real texture colors blend smoothly.

Transparent image pixels become empty space. Square power-of-two textures from 8–256 pixels are supported; mixed sizes are normalized to the largest size.

Save project includes the original source, image adjustments, textures and view. Existing project files still open. Grayscale PNG downloads the adjusted grayscale image at its original dimensions. Block PNG exports the full textured wall. Neither export includes grids or clip-warning colors.

To set up the hosted block library, put your 16×16 PNGs in a textures folder next to this HTML. In the library, click Create texture list and select that folder. Save the generated index.json inside textures and upload the entire folder beside the HTML. For a local test, selecting the folder also loads its textures immediately.

Blur is applied first, before levels, grain, dithering and quantization. Its radius is measured in source-image pixels. Set it to zero to preserve original sharpness. The Source image view always shows the unblurred original.

Clip warning shows final output black in blue and final output white in red. Grain uses a stable seed; Reseed changes its pattern. Transparent source pixels below 50% opacity become empty space. Auto range stretches the source histogram to black and white. A flat image may use fewer shades than selected; no fake pixels are added.

This is a flat texture preview. Game lighting, shaders, and randomized block-face variants are not simulated.
